# 🌌 Acerca de Webify Music

**Webify Music** es un clon de Spotify desarrollado utilizando tecnologías web puras como JavaScript, HTML5 y CSS3, enfocado en ofrecer una experiencia visual moderna y un sistema multimedia dinámico.

La plataforma permite:

- 🎵 Escuchar música online
- 🔎 Buscar canciones y artistas
- ❤️ Guardar favoritos
- 📚 Gestionar playlists
- 🎧 Reproducir audio en tiempo real
- 🌙 Cambiar entre Light/Dark Mode
- 📱 Disfrutar una interfaz responsive

El proyecto está orientado al aprendizaje y práctica de:

- Frontend Development
- JavaScript DOM
- HTML5 Audio API
- Responsive Design
- UI/UX Design
- Aplicaciones multimedia web
